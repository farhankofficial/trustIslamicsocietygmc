TRUST ISLAMIC SOCIETY — GOMAL MEDICAL COLLEGE

Final website package using the TIS logo design supplied by the user.

Files:
- index.html                 Main responsive website
- tis-icon-reference.png     TIS emblem for header/mobile navigation
- tis-full-logo.png          Full TIS logo used in the mobile hero
- website-banner.jpg         Desktop/iPad banner image
- splash-screen.png          Matching mobile splash screen
- splash-preview.png         Preview copy of splash screen
- trust-islamic-society-logo.jpg / .png and mark files are retained as legacy assets for compatibility.

Responsive behavior:
- Desktop and iPad/tablet: image banner is shown.
- Mobile (768px and below): large banner is hidden for a cleaner mobile experience.
- Header logo uses object-fit: contain and overflow-visible so the bottom of the TIS emblem is not cropped.
- Mobile splash appears at 768px and below.

Open index.html in a browser to run the website locally.
